# Технический анализ проекта "Planner Mod" (planner-v2)

Этот отчет содержит подробный разбор текущего состояния репозитория, используемых технологий, структуры файлов и выявленных критических проблем.

## 1. Обзор проекта
Проект представляет собой минималистичное и функциональное веб-приложение для планирования задач. Основные особенности:
- **True Black UI:** Интерфейс, оптимизированный для OLED-экранов с глубоким черным цветом (#0C0C0C).
- **AI-подсказки:** Интеграция с ИИ (Anthropic) для помощи в формулировании задач.
- **Облачная синхронизация:** Использование Supabase в качестве бэкенда.
- **PWA:** Поддержка прогрессивного веб-приложения для работы в оффлайн-режиме.

## 2. Технологический стек
- **Frontend:** React 18.3.1, Vite 5.4.10.
- **Язык:** TypeScript.
- **Бэкенд/БД:** Supabase (PostgreSQL + RLS).
- **ИИ:** Anthropic API (Claude).
- **Основные библиотеки:**
    - `@dnd-kit/core & sortable`: для перетаскивания задач.
    - `@supabase/supabase-js`: клиент для работы с базой данных.
    - `react-hot-toast`: система уведомлений.
    - `canvas-confetti`: визуальные эффекты при выполнении задач.

## 3. Анализ структуры файлов

### Конфигурационные файлы
- **`package.json`**: Содержит список зависимостей. Замечена странность: версия `typescript` указана как `^6.0.3`, что опережает текущий стабильный релиз (5.x).
- **`vite.config.js`**: Стандартная конфигурация Vite для React-проекта.
- **`tsconfig.json` & `tsconfig.node.json`**: Настройки компилятора TypeScript. Включен строгий режим (`strict: true`).
- **`eslint.config.js` & `.eslintrc.cjs`**: В проекте присутствуют оба формата конфигурации ESLint (новый Flat Config и старый CommonJS), что может вызвать конфликты или избыточность.
- **`.prettierrc`**: Настройки форматирования (одинарные кавычки, отсутствие точек с запятой).

### Ресурсы и БД
- **`index.html`**: Главный HTML-файл. Использует шрифты *Cormorant Garamond* и *DM Sans*. Ссылается на отсутствующий файл `favicon.svg`.
- **`supabase_setup.sql`**: Описывает структуру таблицы `tasks`. Важные поля: `id`, `user_id`, `title`, `priority`, `order`, `date_str`, `completed`. Настроены политики безопасности (RLS), ограничивающие доступ пользователей только к своим записям.

### Документация
- **`README.md`**: Описание проекта, инструкции по установке и список горячих клавиш.
- **`AGENTS.md`**: Специализированные инструкции для AI-агентов по работе с данным репозиторием.

## 4. Критические недостатки и уязвимости

### 🔴 ОТСУТСТВИЕ ИСХОДНОГО КОДА
Самая большая проблема: **в репозитории полностью отсутствует папка `src/`**.
- В `index.html` есть вызов `<script type="module" src="/src/main.tsx"></script>`, но самого файла и папки нет.
- Это делает проект неработоспособным в текущем виде.

### 🔴 УТЕЧКА СЕКРЕТНЫХ ДАННЫХ
Файл **`.env`** был зафиксирован в Git. Он содержит:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`
**Рекомендация:** Срочно отозвать эти ключи в панели Supabase и сгенерировать новые. Ключи считаются скомпрометированными, так как они остались в истории коммитов.

### 🟡 ДРУГИЕ НЕДОЧЕТЫ
- **Пропущенные файлы:** Отсутствует `favicon.svg`, на который ссылается HTML.
- **Дублирование конфигов:** Наличие и `eslint.config.js`, и `.eslintrc.cjs` одновременно.
- **Версия TypeScript:** Использование `^6.0.3` может быть ошибкой или использованием экспериментальной версии, что снижает стабильность.

## 5. Итоги и рекомендации
Проект имеет отличную задумку и современный стек, но требует немедленного исправления структуры:
1. **Восстановить исходный код** в папке `src/`.
2. **Очистить историю Git** от файла `.env` и сменить ключи в Supabase.
3. **Привести в порядок конфигурации** (удалить лишние файлы ESLint).
4. **Добавить недостающие ассеты** (иконки).
