# Технический анализ проекта "Planner Mod" (planner-v2)

Этот отчет содержит подробный разбор текущего состояния репозитория, используемых технологий, структуры файлов и выявленных критических проблем. Анализ проведен для версии "mod", которая отличается специфическим набором функций и визуальным стилем.

## 1. Обзор проекта
Проект представляет собой минималистичное и функциональное веб-приложение для планирования задач. Основные особенности:
- **True Black UI:** Интерфейс, оптимизированный для OLED-экранов с глубоким черным цветом (#0C0C0C).
- **AI-подсказки:** Интеграция с ИИ (Anthropic) для помощи в формулировании задач и генерации идей.
- **Облачная синхронизация:** Использование Supabase в качестве бэкенда для хранения данных и аутентификации.
- **PWA и Оффлайн режим:** Поддержка прогрессивного веб-приложения и работы без интернета с последующей синхронизацией.
- **Гостевой режим:** Возможность использования приложения без регистрации через localStorage.

## 2. Технологический стек
- **Frontend:** React 18.3.1, Vite 5.x.
- **Язык:** TypeScript (версия в package.json указана как ^6.0.3, что является необычным выбором, так как стабильная версия на текущий момент — 5.x).
- **Бэкенд/БД:** Supabase (PostgreSQL + RLS).
- **ИИ:** Anthropic API (Claude).
- **Основные библиотеки:**
    - `@dnd-kit`: для реализации функционала перетаскивания (Drag-and-Drop) задач.
    - `@supabase/supabase-js`: клиент для интеграции с базой данных.
    - `react-hot-toast`: система всплывающих уведомлений.
    - `canvas-confetti`: визуальные эффекты ("празднование") при выполнении задач.

## 3. Анализ структуры файлов

### Конфигурационные файлы
- **`package.json`**: Описывает зависимости и скрипты. Присутствуют скрипты для разработки, сборки, линтинга, форматирования и тестирования.
- **`vite.config.js`**: Конфигурация сборщика Vite с плагином для React.
- **`tsconfig.json` & `tsconfig.node.json`**: Настройки TypeScript. Проект настроен на строгую проверку типов.
- **`eslint.config.js` & `.eslintrc.cjs`**: **Дублирование.** В проекте одновременно присутствуют два формата конфигурации ESLint. Рекомендуется оставить один (предпочтительно `eslint.config.js`).
- **`.prettierrc`**: Правила форматирования кода (без точек с запятой, одинарные кавычки, ширина строки 100).
- **`.env`**: **Критическая проблема.** Файл с ключами Supabase находится в репозитории. Ключи скомпрометированы.

### Ресурсы и БД
- **`index.html`**: Точка входа. Использует шрифты *Cormorant Garamond* (для заголовков) и *DM Sans*. Ссылается на `/src/main.tsx` и `/favicon.svg`.
- **`supabase_setup.sql`**: SQL-скрипт для настройки базы данных. Создает таблицу `tasks`, включает Row Level Security (RLS) и настраивает политики доступа, чтобы пользователи видели только свои задачи.

### Документация
- **`README.md`**: Базовое описание проекта, инструкции по запуску и горячие клавиши.
- **`AGENTS.md`**: Инструкции для AI-агентов, работающих с кодом.

## 4. Выявленные недостатки и уязвимости

### 🔴 ОТСУТСТВИЕ ИСХОДНОГО КОДА (Критично)
В текущем репозитории **полностью отсутствует папка `src/`**.
- Файл `index.html` пытается загрузить `/src/main.tsx`, которого нет.
- Команда `npm test` завершается ошибкой, так как не находит файлов тестов.
- Без папки `src/` проект является неработоспособным "скелетом" из конфигурационных файлов.

### 🔴 УТЕЧКА СЕКРЕТНЫХ ДАННЫХ (Безопасность)
Файл **`.env`** содержит рабочие ключи `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
- Эти данные попали в историю коммитов Git.
- **Действие:** Необходимо немедленно отозвать ключи в панели Supabase и сгенерировать новые. Файл `.env` должен быть добавлен в `.gitignore` (исправлено в рамках данного анализа).

### 🟡 ДРУГИЕ НЕДОЧЕТЫ
- **Отсутствующие ресурсы:** Файл `favicon.svg` отсутствует в корне, что вызывает ошибку 404 при загрузке страницы.
- **Избыточность конфигурации:** Наличие двух разных форматов конфига ESLint может привести к путанице при разработке.
- **Версия TypeScript:** Указание версии `^6.0.3` в `package.json` может вызвать проблемы с совместимостью, так как TypeScript 6 еще не выпущен официально.

## 5. Итоги и рекомендации
Проект "Planner Mod" имеет продуманную концепцию и современный стек, но на данный момент находится в нерабочем состоянии из-за отсутствия исходного кода.

**Рекомендации по восстановлению:**
1. **Восстановить исходный код:** Найти и загрузить содержимое папки `src/`.
2. **Безопасность:** Перегенерировать ключи Supabase.
3. **Очистка:** Удалить `.eslintrc.cjs` в пользу `eslint.config.js`. Добавить `favicon.svg`.
4. **Стабилизация:** Изменить версию TypeScript в `package.json` на стабильную (например, `^5.0.0`).
