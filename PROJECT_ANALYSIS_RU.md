# Технический анализ проекта "Планер Мод" (planner-app_mod)

## 1. Обзор проекта
Проект представляет собой современное веб-приложение для планирования задач («Планер ✦»), ориентированное на минимализм, эстетику "True Black" (оптимизация для OLED-дисплеев) и использование искусственного интеллекта для помощи пользователю.

Версия "Мод" отличается использованием TypeScript и интеграцией расширенных функций, таких как Drag-and-Drop.

## 2. Разбор файловой структуры

- **`index.html`**: Точка входа в приложение. Подключает шрифты *Cormorant Garamond* и *DM Sans*, задает мета-теги и подготавливает контейнер `<div id="root"></div>`.
- **`package.json`**: Манифест проекта.
    - **Стек:** React 18, Vite, TypeScript.
    - **Ключевые зависимости:**
        - `@supabase/supabase-js`: Интеграция с бэкендом (БД, аутентификация).
        - `@dnd-kit/*`: Мощная библиотека для реализации перетаскивания (Drag-and-Drop).
        - `canvas-confetti`: Эффекты празднования при выполнении задач.
        - `react-hot-toast`: Всплывающие уведомления.
- **`supabase_setup.sql`**: Скрипт инициализации базы данных.
    - Создает таблицу `tasks` с полями для заголовка, заметок, времени, приоритета, эмодзи и порядка (`order`).
    - Настраивает **RLS (Row Level Security)**, гарантируя, что пользователи видят только свои задачи.
- **`tsconfig.json`** и **`tsconfig.node.json`**: Настройки компилятора TypeScript для обеспечения строгой типизации.
- **`vite.config.js`**: Конфигурация сборщика Vite с плагином для React.
- **`.eslintrc.cjs`** и **`eslint.config.js`**: Настройки линтера (проект находится в процессе перехода на новый формат flat config).
- **`.prettierrc`**: Правила форматирования кода (одинарные кавычки, отсутствие точек с запятой).
- **`README.md`**: Основная документация для разработчиков.
- **`AGENTS.md`**: Инструкции для AI-агентов по работе с репозиторием.

## 3. Ключевые особенности
1. **True Black UI:** Интерфейс в глубоких черных тонах для экономии заряда батареи на мобильных устройствах и снижения нагрузки на глаза.
2. **AI-подсказки:** Интеграция с Anthropic (Claude) для генерации идей и структуры задач.
3. **Облачная синхронизация:** Использование Supabase для хранения данных и аутентификации.
4. **Drag-and-Drop:** Возможность изменять порядок задач вручную (благодаря `@dnd-kit`).
5. **PWA и Offline:** Возможность установки приложения и работа без интернета с последующей синхронизацией.

## 4. Критические недостатки и рекомендации

### 🔴 ОТСУТСТВИЕ ИСХОДНОГО КОДА
Самая серьезная проблема репозитория: **отсутствует папка `src`**. В текущем состоянии проект невозможно запустить или собрать, так как отсутствуют все React-компоненты, хуки и основная логика (`main.tsx`, `App.tsx` и др.).

### 🟡 БЕЗОПАСНОСТЬ
Файл **`.env`** с ключами Supabase (`VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`) закоммичен в репозиторий.
- **Риск:** Хотя ключи "anon" публичные по своей природе, их хранение в Git считается плохой практикой.
- **Рекомендация:** Добавить `.env` в `.gitignore` и перевыпустить ключи.

### 🟡 КОНФИГУРАЦИЯ
Присутствуют два файла конфигурации ESLint (`.eslintrc.cjs` и `eslint.config.js`), что может привести к конфликтам при настройке инструментов разработки.

## 5. Заключение
Проект имеет отличную задумку и современный технологический стек. Однако на данный момент репозиторий является "битым" из-за отсутствия папки `src`. Для восстановления функциональности необходимо перенести исходный код из основной версии проекта или восстановить его из локальных копий.
