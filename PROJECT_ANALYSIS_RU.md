# Полный технический анализ проекта "Планер Мод" (Planner Mod)

Этот документ представляет собой подробный разбор структуры, особенностей и текущего состояния репозитория `planner-v2` (версия "Mod").

---

## 1. Пофайловый анализ проекта

### Конфигурация окружения и сборки
*   **`package.json`**: Основной файл манифеста.
    *   *Зависимости:* React 18.3. Основные библиотеки версии "Mod": `@dnd-kit` (Drag-and-Drop), `canvas-confetti` (эффекты), `react-hot-toast` (уведомления).
    *   *Инструменты:* Vite 5.1, TypeScript 6.0, Vitest.
*   **`vite.config.js`**: Стандартная конфигурация Vite для React-приложения.
*   **`tsconfig.json`**: Строгие настройки TypeScript. Интересно, что `include` указывает на папку `src`, которая отсутствует.
*   **`.eslintrc.cjs` & `eslint.config.js`**: Присутствуют оба формата конфигурации ESLint. Рекомендуется перейти на единый формат (Flat Config).
*   **`.prettierrc`**: Настроено форматирование без точек с запятой и с одинарными кавычками.

### База данных и безопасность
*   **`supabase_setup.sql`**: SQL-схема для Supabase.
    *   Таблица `tasks` включает поле `order` (важно для DND).
    *   Настроены политики безопасности RLS (Row Level Security).
*   **`.env`**: Содержит реальные ключи доступа к Supabase. **Критическая уязвимость!**

### Интерфейс и документация
*   **`index.html`**: Использует шрифты *Cormorant Garamond* и *DM Sans*. Тема "True Black" задана через `theme-color`.
*   **`README.md`**: Описывает функционал: AI-подсказки, оффлайн режим, PWA.
*   **`AGENTS.md`**: Полезные инструкции для разработчиков и ИИ-агентов.

---

## 2. Особенности версии "Mod"

1.  **Интерактивность (Drag-and-Drop):** Использование `@dnd-kit` позволяет пользователю вручную сортировать задачи.
2.  **Эстетика "True Black":** OLED-оптимизированный интерфейс.
3.  **Игровые механики:** Конфетти при завершении задач.
4.  **AI-интеграция:** Поддержка Anthropic API для генерации задач.

## 3. Выявленные недочеты и критические ошибки

### 🔴 КРИТИЧЕСКАЯ ОШИБКА: Отсутствие исходного кода
В репозитории **полностью отсутствует папка `src/`**.
*   **Последствия:** Проект невозможно запустить или собрать. Файл `index.html` ссылается на `/src/main.tsx`, которого нет.
*   **Статус:** Репозиторий сейчас является "пустышкой" без бизнес-логики.

### 🔴 УГРОЗА БЕЗОПАСНОСТИ: Публикация секретов
Файл `.env` был закоммичен в репозиторий.
*   **Риск:** Утечка данных пользователей и несанкционированный доступ к БД.
*   **Предпринятое действие:** `.env` удален из индекса Git и добавлен в `.gitignore`. Однако ключи в панели Supabase следует заменить.

### 🟡 ТЕХНИЧЕСКИЙ ДОЛГ
*   **Дублирование конфигов:** Наличие и `.eslintrc.cjs`, и `eslint.config.js`.
*   **Отсутствие ресурсов:** Ссылка на `favicon.svg` в HTML, но файл отсутствует в корне.
*   **Версия TypeScript:** Указана версия `^6.0.3`, что является очень новой/экспериментальной версией, возможны проблемы с совместимостью.

## Итоговое заключение

Проект обладает отличным потенциалом и современным стеком технологий, ориентированным на продуктивность и эстетику. Однако на данный момент он **нефункционален** из-за отсутствия папки `src/`. Рекомендуется восстановить исходный код из бэкапа или предыдущих версий.
