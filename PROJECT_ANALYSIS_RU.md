# Полный технический анализ проекта "Планер Мод" (Planner Mod)

Этот документ представляет собой подробный разбор структуры, особенностей и текущего состояния репозитория `planner-v2` (версия "Mod").

---

## 1. Пофайловый анализ проекта

### Конфигурация окружения и сборки
*   **`package.json`**: Сердце проекта. Определяет зависимости.
    *   *Зависимости (Dependencies):* Использует React 18.3. Из особенностей "Mod" версии — наличие `@dnd-kit` (для перетаскивания задач), `canvas-confetti` (для визуальных эффектов) и `react-hot-toast` (для уведомлений).
    *   *Инструменты разработки (DevDependencies):* Vite 5.1 (быстрый сборщик), TypeScript 6.0 (строгая типизация), Vitest (тестирование), ESLint и Prettier (качество кода).
*   **`vite.config.js`**: Настройка сборщика Vite. Использует стандартный плагин для React.
*   **`tsconfig.json` & `tsconfig.node.json`**: Настройки TypeScript. Установлен строгий режим (`strict: true`), целевая среда `ES2020` и работа в браузере.
*   **`.eslintrc.cjs` & `eslint.config.js`**: Конфигурации для линтинга. Проект находится в процессе перехода на новый формат конфигов ESLint (Flat Config). Обеспечивают чистоту кода и предотвращают типичные ошибки React.
*   **`.prettierrc`**: Правила форматирования кода: без точек с запятой, одинарные кавычки, ширина строки 100 символов.

### База данных и безопасность
*   **`supabase_setup.sql`**: Сценарий настройки бэкенда в Supabase.
    *   Создает таблицу `tasks` с полями: `id`, `user_id`, `title`, `note`, `time`, `priority`, `repeat`, `emoji`, `tags`, `completed`, `"order"`, `date_str`.
    *   *Важно:* Поле `"order"` необходимо для работы Drag-and-Drop.
    *   Включает RLS (Row Level Security) — пользователи могут видеть только свои задачи.
*   **`.env`**: Содержит секретные ключи доступа к Supabase.

### Интерфейс и документация
*   **`index.html`**: Главная страница.
    *   Использует шрифты *Cormorant Garamond* (для элегантных заголовков) и *DM Sans* (для основного текста).
    *   Настроен цвет темы `#0C0C0C` для реализации режима "True Black".
*   **`README.md`**: Описание проекта, его фишек (AI-подсказки, оффлайн режим, стриксы) и инструкция по запуску.
*   **`AGENTS.md`**: Инструкции для ИИ-разработчиков, описывающие специфику проекта и правила работы с ним.

## 2. Особенности версии "Mod"

1.  **Интерактивность (Drag-and-Drop):** Благодаря `@dnd-kit` пользователь может вручную менять порядок задач, что сохраняется в БД через колонку `order`.
2.  **Эстетика "True Black":** Интерфейс полностью оптимизирован под OLED-дисплеи (абсолютно черный фон), что экономит заряд и бережет глаза.
3.  **Визуальное вознаграждение:** Использование `canvas-confetti` при выполнении задач добавляет элементы геймификации.
4.  **Современный стек:** Использование последних версий React и TypeScript (v6.0) обеспечивает долгосрочную поддержку и надежность кода.
5.  **AI-интеграция:** Поддержка API Anthropic для генерации подсказок к задачам.

## 3. Выявленные недочеты и критические ошибки

### 🔴 КРИТИЧЕСКАЯ ОШИБКА: Отсутствие исходного кода
В репозитории **полностью отсутствует папка `src/`**.
*   **Что это значит:** В проекте нет ни одного React-компонента, ни логики приложения. Файл `index.html` пытается загрузить `/src/main.tsx`, которого не существует. Проект в текущем виде **неработоспособен**.

### 🔴 УГРОЗА БЕЗОПАСНОСТИ: Публикация секретов
Файл `.env` с ключами Supabase находится в открытом доступе в репозитории.
*   **Что это значит:** Любой человек может подключиться к вашей базе данных.
*   **Решение:** Срочно сменить ключи в панели Supabase и добавить `.env` в `.gitignore`.

### 🟡 НЕДОЧЕТЫ ДОКУМЕНТАЦИИ И РЕСУРСОВ
*   **Отсутствие фавикона:** В `index.html` указан `/favicon.svg`, но самого файла в корне нет.
*   **Пустые ссылки:** В `README.md` используются placeholder-картинки вместо реальных скриншотов приложения.

## Итоговое заключение

Проект "Планер Мод" задуман как продвинутая версия планировщика с отличным набором инструментов. Однако на данный момент репозиторий находится в критическом состоянии: **главный рабочий код (папка `src`) утерян**, а ключи доступа скомпрометированы. Для восстановления проекта необходимо в первую очередь вернуть исходный код и обеспечить безопасность данных.
