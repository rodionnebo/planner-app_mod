# Полный технический анализ проекта "Планер Мод" (Planner Mod)

## 1. Описание проекта
Проект представляет собой модифицированную версию приложения для планирования задач («Планер ✦»). Основной упор сделан на минималистичный дизайн («True Black UI»), использование искусственного интеллекта для помощи в формулировании задач и интеграцию с Supabase для синхронизации данных.

## 2. Пофайловый разбор

### Конфигурация и сборка
*   **`package.json`**: Определяет зависимости проекта. Используются:
    *   `react`, `react-dom` (v18.3.1) — ядро интерфейса.
    *   `@dnd-kit` — библиотека для реализации Drag-and-Drop (перетаскивание задач).
    *   `canvas-confetti` — эффекты конфетти при завершении задач.
    *   `react-hot-toast` — всплывающие уведомления.
    *   `@supabase/supabase-js` — клиент для работы с базой данных.
    *   `typescript` — используется версия ^5.6.2.
    *   `vite` — инструмент сборки.
    *   `vitest` — фреймворк для тестирования.
*   **`vite.config.js`**: Стандартная конфигурация Vite с поддержкой React.
*   **`tsconfig.json` & `tsconfig.node.json`**: Настройки TypeScript. Проект ориентирован на современные стандарты (ES2020), включен строгий режим (`strict: true`).
*   **`.eslintrc.cjs` & `eslint.config.js`**: Присутствуют оба формата конфигурации ESLint. Это указывает на переходный период обновления инструментов линтинга. Настроены правила для React и предотвращение типичных ошибок.
*   **`.prettierrc`**: Правила форматирования (без точек с запятой, одинарные кавычки, ширина строки 100).

### База данных
*   **`supabase_setup.sql`**: SQL-скрипт для настройки БД в Supabase.
    *   Создает таблицу `tasks` со всеми необходимыми полями (включая `order` для сортировки и `date_str` для группировки по датам).
    *   Включает Row Level Security (RLS), гарантируя, что пользователи видят только свои данные.
    *   Создает индексы для ускорения запросов.

### Окружение и документация
*   **`index.html`**: Входная точка приложения. Подключает шрифты *Cormorant Garamond* и *DM Sans*. Устанавливает темный фон для OLED-экранов.
*   **`.env`**: **Внимание!** Файл содержит активные ключи Supabase. Это критическая ошибка безопасности (см. ниже).
*   **`README.md`**: Описывает основные фичи, горячие клавиши и инструкции по развертыванию.
*   **`AGENTS.md`**: Содержит технические инструкции для ИИ-помощников, работающих с этим кодом.

## 3. Особенности и преимущества ("Mod" версия)
1.  **Интеллектуальные подсказки**: Интеграция с Anthropic (Claude) для помощи пользователю в планировании.
2.  **Drag-and-Drop**: Полноценная поддержка изменения порядка задач вручную.
3.  **Геймификация**: Система стриксов (🔥) и визуальные празднования (конфетти).
4.  **True Black UI**: Идеально для OLED-экранов и работы в темноте.
5.  **PWA**: Поддержка работы в оффлайне и установки как приложения.

## 4. Критические недостатки и рекомендации

### 🔴 КРИТИЧЕСКАЯ ОШИБКА: Отсутствие исходного кода (`src/`)
В текущем состоянии ветки `main` полностью отсутствует папка `src/`. Это означает, что в репозитории нет компонентов, логики и самого приложения — только конфигурационные файлы. Приложение **невозможно запустить или собрать**.
*   *Рекомендация:* Проверить локальные копии или историю Git для восстановления исходного кода.

### 🔴 УТЕЧКА СЕКРЕТОВ
Файл `.env` закоммичен в репозиторий. Любой человек может получить доступ к вашей базе данных Supabase.
*   *Рекомендация:* Срочно сгенерировать новые ключи в Supabase и добавить `.env` в `.gitignore`.

### 🟡 ОТСУТСТВИЕ РЕСУРСОВ
В `index.html` указан `/favicon.svg`, но самого файла в корне нет. Также в `README.md` используются ссылки-заглушки для скриншотов.

### 🟡 КОНФЛИКТ КОНФИГУРАЦИЙ
Наличие и `.eslintrc.cjs`, и `eslint.config.js` может приводить к путанице. Рекомендуется полностью перейти на новый формат (Flat Config).

## Итог
Проект "Планер Мод" обладает отличным стеком технологий и продуманной архитектурой базы данных. Однако на данный момент он **сломан** из-за отсутствия папки `src/` и небезопасен из-за открытых ключей доступа.
